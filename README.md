# REST-API-LF9
Hier dokumentiere ich die Erarbeitung meiner REST-API die ich als Projekt für die Berufsschule in dem Lernfeld 9 erstellen muss.

## Einrichtung

1. Erstelle eine virtuelle Umgebung im Projektordner:
   ```bash
   python3 -m venv venv
   ```
2. Aktiviere die Umgebung:
   ```bash
   source venv/bin/activate
   ```
3. Installiere die benötigten Pakete:
   ```bash
   pip install -r requirements.txt
   ```
4. Starte den Server:
   ```bash
   python benas-Umsetzung-API.py
   ```

Diese Vorgehensweise stellt sicher, dass `Flask` nur für dieses Projekt installiert wird und nicht global auf dem System.
